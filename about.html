About this project

Niki Durzynski

Lantern quest is a Web Programming Project 1 site based on the Quest Explorer track and Adventure Pack.

The site uses HTML and one shared CSS file. The lantern and cloud are CSS shapes. No outside images or JavaScript are used.

Using the site

Use Tab to move between links and Enter to open them. The skip link goes straight to the page content. Reduced-motion settings turn off the animations.
